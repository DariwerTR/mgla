# Белая мгла (WhiteMist) · этап 1 «Тихий пролог»

Хоррор-мод для Fabric. Мир накрывает густой белый туман, и в нём появляются **Слушатели**: слепые существа,
которые охотятся на звук. Бег, ломание блоков, открытые двери, полученный урон, всё это слышно. Шерсть заглушает.

**Платформа: Minecraft 26.3 · Fabric Loader ≥ 0.20.1 · Fabric API 0.165.2+26.3 · Java 25**
(версии сверены с официальным `fabric-example-mod` от 07.11.2026; для другой версии игры мод нужно пересобирать).

## Сборка

```bash
./gradlew build          # готовый мод: build/libs/whitemist-0.1.0.jar (не *-sources.jar)
./gradlew runClient      # запустить игру с модом для проверки
```
Положите `whitemist-0.1.0.jar` и Fabric API в папку `mods`. Для сборки нужен установленный **JDK 25** (Gradle сам его не скачивает).

## Сборка через GitHub (без установки Java у себя)
В проекте есть `.github/workflows/build.yml`. Положите **содержимое** папки `whitemist/` в корень репозитория (не саму папку) и запушьте в `main`:
1. Вкладка **Actions** → запуск `build` (или кнопка *Run workflow*).
2. Успех: внизу страницы запуска, в **Artifacts**, лежит `whitemist-jar`. Внутри готовый мод.
3. Ошибка компиляции: откройте шаг `build` и скопируйте красные строки (`error:`), либо скачайте артефакт `build-log`. Пришлите их мне.

Файлы `gradlew`, `gradle/wrapper/*` и `.gitattributes` нужны в репозитории обязательно. Если в репозитории уже были `build.gradle`, `gradle.properties`
или `fabric.mod.json`, они будут заменены: сделайте коммит заранее, чтобы можно было сравнить.

## Как проверить мод за пять минут
1. Создайте мир (лучше **Hardcore**: «одна жизнь» обеспечивает сама игра) и выполните `/whitemist start`.
2. Туман нарастает 2 минуты (2400 тиков). Видимость падает до ~22 блоков, небо сереет.
3. Когда туман набрал силу, вокруг игрока появляются Слушатели. Вы услышите их щелчки и сердцебиение раньше, чем увидите.
4. Бегите: шкала шума (справа внизу) краснеет, Слушатели идут на звук. Идите приседая или по ковру/шерсти: шкала зелёная, вас не слышат.
5. `/whitemist stop` плавно рассеивает туман (2 минуты); когда он полностью исчез, Слушатели растворяются ещё через 10 секунд.

Если тумана нет, а команда прошла, проверьте часы вручную: `/time of whitemist:mist set 2400`.
Слушателя, вызванного через `/summon` в ясную погоду, мод растворит через 10 секунд: так задумано (они часть мглы), сначала запустите `/whitemist start`.

## Механики
| Что | Как работает |
|---|---|
| **Шум** | Каждое действие имеет громкость = радиус слышимости в блоках: шаг 6, бег 14, приседание 1.5, ломание блока 16, использование блока 9 (в приседе вдвое тише), удар 12, получение урона 18. |
| **Шерсть** | Тег `minecraft:dampens_vibrations` (шерсть, ковры, плиты и ступени из шерсти). Под ногами: шум ×0.25. Между источником и Слушателем: каждый блок ×0.5. |
| **Индикатор шума** | Полоска справа внизу показывает ваш шум **прямо сейчас** по тем же формулам, что и на сервере. Отключается в конфиге. |
| **Слушатель** | Слеп, ходит бесшумно, слышит звук, идёт к самому «интересному» (громкому и близкому). Всё, что стоит вплотную, чувствует и бьёт (по умолчанию 3.5 сердца). |
| **Мгла волнами** | Ясно → сгущается (2 мин) → густая (5–10 мин) → редеет (2 мин). Каждая пережитая волна делает следующую дольше, паузы короче, а Слушателей больше. Под землёй Слушатели почти не появляются, но забрести туда на звук могут. |

Команды: `/whitemist status` (всем), `/whitemist start | stop | reload` (операторам).

## Конфиг `config/whitemist.json`
Создаётся при первом запуске. Время в тиках (20 = секунда, 24000 = игровые сутки). Битый файл не ломает игру: берутся значения по умолчанию.

| Параметр | Смысл |
|---|---|
| `firstMistDelayTicks` | ясная погода до первой мглы в новом мире (24000) |
| `clearTicksMin/Max`, `activeTicksMin/Max` | длины пауз и густой фазы |
| `escalationPerMist` | на сколько растёт каждая следующая волна (0.10 = +10%) |
| `maxListenersPerPlayer` | сколько Слушателей на игрока (+1 за каждые две волны, до +4) |
| `listenerDamage` | урон удара (2.0 = сердце) |
| `listenerHearingScale` | слух Слушателей: 0.5 слабее, 1.5 острее |
| `noise*`, `wool*Factor` | громкости действий и степень заглушения шерстью |
| `showNoiseMeter` | индикатор шума |

Плотность тумана правится данными: `src/main/resources/data/whitemist/timeline/mist.json`, значение `22.0` у `fog_end_distance`
(это дальность видимости в блоках на пике; меньше = гуще). Правится в исходниках, затем пересборка.

## Что проверено, а что нет (честно)
Я **не мог запустить Gradle и игру** (в моей среде закрыт доступ к maven.fabricmc.net и серверам Mojang),
поэтому финальную компиляцию делаете вы. Что я сделал вместо неё, подробно в `docs/VERIFICATION_REPORT.md`:

| Проверено **запуском** | Проверено **по реальному коду 26.3** | **Не подтверждено** (нужна ваша сборка) |
|---|---|---|
| Синтаксис всех `.java` (парсер) | Все 174 импорта найдены в Fabric API 26.3, NeoForge 26.3.x и референсе Fabric Docs | Вызов `getNavigation().moveTo(...)` (в корпусах 26.3 не встречается) |
| Нет пропущенных и лишних импортов | Данные тумана сверены с форматом ванильных `timeline` и реестром атрибутов | Вызов `withSuppressedOutput()` в `ClockBridge` |
| Чистая логика (цикл мглы, шум, конфиг) собрана с `-Xlint` и прошла 1035 проверок | Модификаторы `alpha_blend`/`add` подтверждены официальной статьёй Mojang | Внешний вид тумана и баланс (нужен глаз и игра) |
| JSON, ключи lang (ru/en), совпадение часов мира, размеры и UV текстуры, звуки ванили | `Entity.moveTo` в 26.3 заменён на `snapTo`: мод его не использует | Поведение ИИ Слушателя в живой игре |
| Сам верификатор проверен на 11 намеренных поломках (ловит 11 из 11) | | |

Обе неподтверждённые строки изолированы в **одном методе каждая** (`ListenerEntity.walkTo`, `ClockBridge.run`).
Если сборка упадёт, пришлите мне лог: правка займёт одну строку.

## Структура
```
src/main/java/com/whitemist/
  core/      чистая логика без Minecraft: MistCycle, NoiseMath (тестируется отдельно)
  config/    WhiteMistConfig
  noise/     NoiseManager, PlayerNoiseTracker, NoiseListeners, NoiseTags
  mist/      MistController, MistSavedData, ListenerSpawner, ClockBridge
  entity/    ListenerEntity, ModEntities
  command/   /whitemist
src/client/java/com/whitemist/client/   модель, рендерер, индикатор шума
src/main/resources/data/whitemist/      world_clock + timeline (туман без миксинов)
tools/       мои скрипты проверки (run_selftest.sh работает у вас: нужен JDK 17+)
docs/        DEV_BRIEF.md (рабочий промпт), VERIFICATION_REPORT.md
```
