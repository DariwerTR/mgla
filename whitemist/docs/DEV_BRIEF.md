# DEV BRIEF — «Белая мгла» (рабочий промпт для самого себя)

> Этот файл я написал себе перед началом работы и сверялся с ним на каждом шаге.
> Он же служит чек-листом самопроверки.

## 1. Роль и цель
Я старший разработчик Fabric-модов. Делаю хоррор-мод **«Белая мгла»**: мир накрывает густой туман,
в нём живут слепые существа, которые охотятся на **звук**. Страх строится на механиках, а не на скримерах.
Качество важнее объёма: лучше меньше фич, но каждая проверена.

## 2. Целевая платформа (проверено по источникам на 12.11.2026, не по памяти)
| Что | Значение | Источник |
|---|---|---|
| Minecraft | **26.3** (релиз 15.09.2026, без обфускации, имена Mojang) | fabricmc.net/2026/09/15/263 |
| Fabric Loader | 0.20.1 | fabric-example-mod, коммит от 07.11.2026 |
| Fabric Loom | 1.19-SNAPSHOT, плагин `net.fabricmc.fabric-loom` | там же |

Следствия: НЕТ `mappings`, НЕТ `modImplementation` (только `implementation`), имена классов Mojang
(`Identifier`, `ServerLevel`, `EntityTypes.*`), `Entity.snapTo` вместо `moveTo`.
Нельзя полагаться на мои знания о 1.21.x: часть API переименована.

## 3. Столпы дизайна
1. **Звук как валюта.** Каждое действие игрока имеет громкость (радиус слышимости в блоках).
2. **Шерсть заглушает.** Шерсть и ковры под ногами и на пути звука гасят шум (ванильный тег `dampens_vibrations`).
3. **Слышишь раньше, чем видишь.** Существа беззвучно ходят, но щёлкают; туман ограничивает обзор.
4. **Честная жестокость.** Игрок всегда видит, насколько он шумит (индикатор). Смерть режимом мира (Hardcore), а не модом.
5. **Мгла приходит волнами** и со временем становится дольше и чаще.

## 4. Объём этапа 1 («Тихий пролог») — вертикальный срез
В объёме: цикл мглы + туман; система шума; существо «Слушатель»; индикатор шума; команды; конфиг; ru/en.
Вне объёма (этап 2+): рассудок, лагеря и NPC, звукоизоляционные блоки, оружие-отвлекалки, боссы, структуры.

## 5. Архитектурные правила
- **Ноль миксинов.** Туман делается данными (world_clock + timeline + environment attributes), часы мира
  двигает сервер командой `/time of whitemist:mist set N`.
- **Чистая логика отдельно от Minecraft** (`com.whitemist.core`): цикл мглы, математика шума, конфиг.
  Она компилируется и тестируется без игры.
- **Минимум API ванили.** Каждый вызов ванильного API должен быть либо подтверждён в корпусе 26.3
  (Fabric API / NeoForge 26.3.x / Fabric Docs), либо изолирован и помечен как «неподтверждено».
- **Сервер авторитетен.** Клиент только рисует (HUD, рендер). Клиентский код только в `src/client`.
- **Никогда не падать от конфига.** Битый файл = дефолты + предупреждение в лог.
- **Ломающий JSON хуже ломающего Java:** ошибка в `timeline`/`world_clock` не даёт загрузить мир.
  Эти файлы сверяются с форматом ванильных данных.

## 6. Протокол самопроверки (что реально запускаю)
1. Парсинг ВСЕХ `.java` деревом разбора (tree-sitter) на синтаксические ошибки.
2. Компиляция и юнит-тесты чистой логики (`javac`, JDK 21) и компиляция конфига со Gson-заглушкой.
3. Каждый `import net.minecraft.*` / `net.fabricmc.*` ищется в корпусах 26.3. Не найден = в отчёт.
4. Каждое имя вызываемого метода сверяется с корпусом (ловит переименования вроде `moveTo`→`snapTo`).
5. JSON: синтаксис, ключи timeline сверены с реестром `environment_attribute` и форматом ванильных `timeline`.
6. Ресурсы: ключи lang для всех зарегистрированных сущностей, текстура существует и её размер совпадает
   с `LayerDefinition.create(..., W, H)`, UV всех кубоидов лежат внутри текстуры и не пересекаются.
7. Звуки: все идентификаторы существуют в ванильном реестре `sound_event`.
8. Запрещённые паттерны: имена Yarn, `modImplementation`, `localStorage`-подобные штуки, `moveTo(` с 5 аргументами.
